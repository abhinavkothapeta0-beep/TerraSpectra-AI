# TerraSpectra-AI 🌱

### Hyperspectral Crop Disease Forecasting

## 📌 About
TerraSpectra-AI is a Data Science and Machine Learning project focused on analyzing hyperspectral data to identify crop health conditions and predict potential plant diseases.

## 🎯 Objectives
- Analyze hyperspectral crop data.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Develop Machine Learning models.
- Evaluate model performance.
- Support early crop disease detection.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Machine Learning
